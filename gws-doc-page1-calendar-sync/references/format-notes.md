# Format Notes

## Planner Detection Rule

- 문서 본문에서 `table` 블록을 순차 탐색한다.
- 첫 번째로 `오늘의 업무/일정` 헤더를 포함한 테이블을 1페이지 플래너 테이블로 간주한다.

## Row Mapping Rule

- `row[0]`: 업무 제목
- `row[4]`: 예상 업무 시간 (`HH:MM ~ HH:MM` 형식)
- `row[5]`: 우선순위 컬럼이지만, 폰트 아이콘 문자(`\ue907`)로 추출될 수 있으므로 저장에 사용하지 않는다.

## Event/Task Split Rule

- `row[4]`가 시간 범위면 Calendar 이벤트 생성
- `row[4]`가 비어 있으면 Tasks 할 일 생성
- 단, `오늘의 업무/일정`의 모든 행이 시간 미기재면 Tasks 자동 생성을 중단하고 사용자 수동 시간 할당을 우선한다.

## Date Rule

- 문서 헤더의 `날짜` 셀 값(예: `2026.04.20`)을 우선 사용
- `--date` 인자가 있으면 문서 날짜보다 우선 적용
- 둘 다 없으면 실행 시점의 오늘 날짜 사용
