## 구조

각 스킬은 독립된 디렉터리로 관리되며, 일반적으로 다음 구조를 사용합니다.

```text
skill-name/
├── SKILL.md
├── agents/       # 선택: 에이전트 메타데이터
├── references/   # 선택: 참고 문서
├── scripts/      # 선택: 실행 도구
├── assets/       # 선택: 이미지 등 리소스
└── examples/     # 선택: 예제 산출물
```

`SKILL.md`의 frontmatter에는 스킬 이름과 사용 조건을 포함한 설명을 정의합니다. `.system` 디렉터리는 시스템 관리 스킬을 별도로 보관합니다.
